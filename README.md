# Java Learning 

A structured collection of Java programs built while learning the fundamentals of Object-Oriented Programming and core Java concepts from scratch.

## What's Inside

## Concepts Covered

- Variables, Data Types & Operators
- Conditional Statements & Loops
- Arrays & ArrayLists
- String Methods
- HashMap & Collections
- Object-Oriented Programming (OOP)
  - Classes & Objects
  - Inheritance
  - Polymorphism
  - Encapsulation
- User Input handling (Scanner)
- Switch Statements

## Projects Highlight

### Calculator
A fully functional calculator built using Switch-case statements supporting basic arithmetic operations.

### Book Management System
An OOP-based mini project demonstrating:
- `Book.java` — Base class
- `AudioBook.java` — Extends Book (Inheritance)
- `Ebooks.java` — Extends Book (Polymorphism)
- `users.java` — User interaction layer
